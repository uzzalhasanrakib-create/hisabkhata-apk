হিসাবখাতা (HISABKHATA) — ফোনে ইনস্টল ও APK তৈরি করার সহজ নির্দেশিকা
====================================================================

পদ্ধতি ১: কোনো ঝামেলা ছাড়াই সরাসরি ফোনে ইনস্টল করুন (১০ সেকেন্ডে)
-------------------------------------------------------------------
১. প্রদত্ত `HisabKhata_Mobile_App.html` (অথবা এই ZIP-এর ভেতরের `www/index.html`) ফাইলটি আপনার অ্যান্ড্রয়েড ফোনে ডাউনলোড করুন।
২. ফাইলটি Chrome ব্রাউজারে ওপেন করুন।
৩. উপরের ডানদিকের ৩-ডট (⋮) মেনু থেকে "Add to Home screen" বা "Install app" বাটনে ট্যাপ করুন।
৪. সাথে সাথে আপনার ফোনের হোম স্ক্রিনে "হিসাবখাতা" অ্যাপ ইনস্টল হয়ে যাবে এবং ইন্টারনেট ছাড়াই (Offline) কাজ করবে!

পদ্ধতি ২: ১ ক্লিকে সরাসরি .APK ফাইল তৈরি করুন (৩০ সেকেন্ডে)
--------------------------------------------------------------
১. আপনার ব্রাউজারে https://www.webintoapp.com অথবা https://appsgeyser.com ওপেন করুন।
২. সেখানে "HTML to APK" অপশনে গিয়ে `HisabKhata_Mobile_App.html` (অথবা এই `HisabKhata_Android_APK_Project.zip`) ফাইলটি আপলোড করুন।
৩. অ্যাপের নাম দিন "হিসাবখাতা" এবং "Make App / Download APK" বাটনে ক্লিক করলেই রেডিমেড `.apk` ফাইল পেয়ে যাবেন।

পদ্ধতি ৩: Android Studio বা GitHub Actions দিয়ে অফিশিয়াল APK বিল্ড
-------------------------------------------------------------------
এই ZIP ফাইলের ভেতর সম্পূর্ণ Native Android WebView প্রজেক্ট (`android/` ফোল্ডার) এবং `.github/workflows/build-apk.yml` দেওয়া আছে।
- এটি একটি GitHub Repository-তে আপলোড করলেই GitHub Actions স্বয়ংক্রিয়ভাবে `HisabKhata-Android-APK.apk` তৈরি করে দেবে।
- অথবা Android Studio-তে `android/` ফোল্ডারটি ওপেন করে `Build > Build Bundle(s) / APK(s) > Build APK(s)` চাপলেই `.apk` তৈরি হয়ে যাবে।
