১. এই HisabKhata_Mobile_App.html ফাইলটি আপনার ফোনে ডাউনলোড করে Chrome ব্রাউজারে খুলুন।

২. নিচের বাটনে ক্লিক করুন অথবা Chrome-এর ডানদিকের ৩-ডট (⋮) মেনু থেকে "Add to Home screen" / "Install app" চাপুন। এটি আপনার ফোনে আসল অ্যাপের মতো ফুল-স্ক্রিনে ও অফলাইনে চলবে!

পদ্ধতি ২: ১ ক্লিকে .APK ফাইল তৈরি (৩০ সেকেন্ডে)

আপনি যদি সরাসরি .apk ফাইল চান, তবে ডাউনলোড করা HisabKhata_Mobile_App.html অথবা HisabKhata_Android_APK_Project.zip ফাইলটি নিচের যেকোনো ফ্রি টুলে আপলোড করে Build APK চাপুন:

  • WebIntoApp.com (HTML to APK)
  • AppsGeyser.com (ZIP/HTML to APK)
  • GitHub Actions (প্রদত্ত ZIP ফাইলে অটো-APK বিল্ডার যুক্ত আছে)
